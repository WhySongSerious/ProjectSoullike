# 팀장 전달문

우리 팀은 송재혁·천지민·이다윤 3명으로 11월 초까지 전투 데모를 완성합니다. 우선 11월 6일을 목표로 잡고 첫 회의에서 날짜와 주간 가용시간을 확정하겠습니다.

재혁은 팀 운영과 통합, 플레이어 전투, VFX·애니메이션을 맡습니다. 지민은 기존 보스 작업을 이어 보스 AI·패턴·공격 판정과 전투 안정화를 맡습니다. 다윤은 기획과 아트 역할을 함께 맡아 패턴·수치·UI/리소스와 플레이테스트를 정리합니다.

이미 있는 이동·카메라·공격 콤보·락온·보스 상태 머신을 활용해서 회피·스태미나·피격을 연결하고, 보스전 시작부터 사망/승리·재시작까지 완성하는 것이 우선입니다. 매주 하나의 목표를 정하고 실제 플레이 가능한 결과로 리뷰하겠습니다.

업무는 GitHub 이슈로 관리합니다. 자기 이름의 이슈에서 완료 기준을 확인하고, 진행/막힘/PR 또는 산출물 링크를 남겨주세요. 씬과 Animator를 동시에 수정하지 않도록 먼저 작업자를 정하고, 다른 한 명이 확인한 뒤 완료 처리하겠습니다.

QR을 찍으면 휴대폰이 게임 컨트롤러가 되는 기능도 아이디어로 두고 있습니다. 필수 전투가 안정되고 여유가 있으면 진행하고, 이번 데모의 필수 항목으로 약속하지는 않겠습니다.

먼저 아래 팀 허브에서 자기 작업을 확인하고, Unity 6000.3.21f1로 개발 브랜치를 실행해 주세요. 첫 회의에서 각자 가능한 시간, 필수 범위, 이번 주 완료 기준을 맞추겠습니다.
